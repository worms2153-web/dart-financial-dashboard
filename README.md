# 연결재무제표 자동 분석 대시보드

DART(전자공시) 연결재무제표를 자동으로 수집하고, 핵심 재무지표 계산과 이상 징후 탐지까지 해서
Streamlit 대시보드로 보여주는 프로젝트입니다.

**배포 링크:** (배포 후 여기에 추가)

## 주요 기능

- **자동 수집**: OpenDART API로 종목코드만 넣으면 연도별 연결재무제표(사업보고서)를 CSV로 저장
- **지표 계산**: 영업이익률, ROE/ROA(평균자본 기준), 부채비율, 유동비율, 순현금, FCF 등
- **이상 징후 탐지** (기준값은 대시보드에서 조절 가능)
  - 매출채권 증가율이 매출 증가율보다 과도하게 빠른 경우
  - 재고자산 증가율이 매출원가 증가율보다 과도하게 빠른 경우
  - 영업현금흐름이 순이익에 못 미치는 경우 (순손실 연도는 계산 제외)
  - 영업이익률 급락, 부채비율 급등, FCF 적자
- **대시보드**: 회사 선택, 수익성/안정성/현금흐름 차트, 경고 점검표, 원본 대조용 표(백만원 단위)

## 프로젝트 구조

| 파일 | 역할 |
|---|---|
| `dart_fetch.py` | DART API 호출 -> `data/{종목코드}_CFS_11011.csv` 저장 |
| `metrics.py` | 계정과목 추출(계정ID 우선, 계정명 보조) + 재무지표 계산 |
| `anomalies.py` | 이상 징후 점검 규칙 |
| `app.py` | Streamlit 대시보드 (위 모듈을 재사용) |

## 실행 방법

```bash
pip install -r requirements.txt

# 1) 데이터 수집 (OpenDART API 키 필요, 처음 실행 시 입력하면 .env에 저장)
python dart_fetch.py

# 2) 대시보드 실행
streamlit run app.py
```

수집할 회사는 `dart_fetch.py` 상단의 `STOCK_CODES`에 종목코드를 추가하면 됩니다.
API 키는 `.env`에 저장되며 저장소에는 포함되지 않습니다.

## 한계 및 주의

- 이상 징후 기준값(예: 10%p, 0.8배)은 임의로 정한 값이며, **경고는 분식 판정이 아니라 확인이 필요한 신호**입니다.
- 계정과목 이름/코드가 회사마다 달라서, 새 회사를 추가하면 못 찾은 계정이 없는지 대시보드 경고를 확인해야 합니다.
- 연간 연결 사업보고서만 다룹니다 (분기 데이터와 누적->단일분기 변환은 미구현).
- 금융업(은행/보험/증권)은 부채비율 등 지표의 해석 기준이 달라 동일한 기준으로 비교하면 안 됩니다.
